# رصد خبر — داشبورد زندهٔ تحلیل اخبار

داشبورد فارسی (RTL) برای رصد، ترجمه و تحلیل خودکار اخبار فارسی و بین‌المللی. داده‌ها از خوراک‌های RSS/Atom منابع مختلف خوانده می‌شوند، خبرهای انگلیسی به فارسی ترجمه می‌شوند و همهٔ شاخص‌ها به‌صورت درصد محاسبه و نمایش داده می‌شوند.

## چه چیزی اصلاح و اضافه شد

- **به‌روزرسانی خودکار هر ۵ دقیقه**: سرور داخلی (`server.mjs`) هر ۵ دقیقه داده را بازتولید می‌کند و صفحه از طریق نظرسنجی داده + رویدادهای SSE بدون بارگذاری مجدد تازه می‌شود؛ شمارندهٔ معکوس و دکمهٔ توقف/فعال‌سازی هم در داشبورد هست.
- **ترجمهٔ خودکار اخبار انگلیسی به فارسی**: عنوان و خلاصهٔ هر خبر انگلیسی با حافظهٔ نهان ترجمه می‌شود. موتور اصلی «Google دسته‌ای» است (چند متن در یک درخواست، حدود ۱۰ تا ۳۰ برابر سریع‌تر از تک‌درخواستی)؛ اگر Google از IP میزبان محدود شود، به‌طور خودکار Bing (چند نشست موازی) جایگزین می‌شود و MyMemory و LibreTranslate و در صورت تنظیم، LLM اختیاری هم در دسترس‌اند؛ عنوان اصلی خبر در داده، اکسل و پیوند اصل خبر حفظ می‌شود. درصد کیفیت ترجمه برای هر خبر و درصد پوشش ترجمه نمایش داده می‌شود؛ خبرهای در انتظار ترجمه با برچسب مشخص و متن اصلی نشان داده می‌شوند.
- **همهٔ خبرها**: هیچ محدودیت زمانی (۲۴ ساعته) روی خروجی نیست؛ همهٔ موارد خوراک هر منبع دریافت، یکسان‌سازی، حذف تکراری و خوشه‌بندی می‌شوند و در داشبورد با دکمهٔ «نمایش بیشتر» قابل مرور است.
- **درصد در همه‌جا**: سهم هر موضوع، سهم هر منبع، درصد اهمیت هر خبر (با تفکیک تازگی/اعتبار منبع/پوشش/موضوع/احساس)، درصد پوشش خبرهای چندمنبعی، درصد احساس، درصد کیفیت ترجمه و درصد سلامت منابع؛ این درصدها در `data.json`، خلاصهٔ تحلیلی، هشدارها و برگه‌های اکسل محاسبه می‌شوند.
- **قیمت طلا و دلار**: نرخ دلار، یورو، درهم، گرم طلای ۱۸ و ۲۴ عیار، مثقال، سکه امامی و انس طلای جهانی در تابلوی «قیمت طلا، سکه و دلار» با مقدار تغییر، درصد تغییر روزانه، ساعت به‌روزرسانی، نام منبع هر کارت و معادل خوانا (هزار/میلیون/میلیارد) نمایش داده می‌شود؛ همهٔ نرخ‌های داخلی به **تومان** است.
- **زنجیرهٔ سه‌مرحله‌ای منابع نرخ**: **TGJU** (اصلی) → **نرخ‌آرا** (`nerkhara.com`) → **ایران‌مارکت** (فایل ثابت گیت‌هاب) و برای انس جهانی **CoinGecko**. اگر دو منبع مسدود یا بی‌پاسخ باشند، نرخ‌ها از مرحلهٔ سوم تازه می‌مانند و اگر هیچ منبعی پاسخ ندهد، هر نرخ آخرین مقدار موفق خودش را با برچسب «قدیمی» نگه می‌دارد. منشأ هر نرخ در `source` همان آیتم و در `markets.providers` ثبت می‌شود.
- **هشدار اختلاف منابع**: در هر اجرا دست‌کم دو منبع خوانده می‌شود؛ اگر نرخ یک آیتم بین آن‌ها بیش از **۳٪** اختلاف داشته باشد، کارت همان آیتم نشان «اختلاف منابع» می‌گیرد و هشدار «دادهٔ مشکوک» با مقدار و منشأ هر دو نرخ زیر تابلو نمایش داده می‌شود (آستانه در `markets.divergence_threshold_percent` و جزئیات در `markets.warnings`).
- **نمودار روند قیمت**: چهار نمودار برای دلار، گرم طلای ۱۸ عیار، سکه امامی و انس جهانی، با انتخاب بازهٔ ۷ / ۳۰ / ۶۰ روز که در مرورگر ذخیره می‌شود. نمونه‌ها در هر اجرا در `markets.history` ثبت می‌شوند (تا ۷۲۰ نقطه) و بار اول از آرشیو روزانهٔ نرخ‌آرا و CoinGecko پر می‌شود تا نمودار از همان آغاز خوانا باشد.
- **بازبینی حالت‌های پشتیبان**: با `?demo=backup` و `?demo=offline` (یا لینک‌های فوتر) ظاهر تابلو در حالت منبع جایگزین و حالت قطع کامل منابع دیده می‌شود؛ این حالت‌ها فقط نمایشی‌اند و دادهٔ واقعی را تغییر نمی‌دهند. نرخ‌ها در `data.json` (کلید `markets`)، خلاصهٔ اجرایی و برگهٔ «بازار» اکسل هم می‌آیند.
- **تحلیل کامل**: خلاصهٔ اجرایی، هفت شاخص تحلیلی، نمودار تراکم ساعتی ۲۴ ساعت گذشته، روند یک‌ساعتهٔ موضوع‌ها، هشدارهای خودکار و خروجی اکسل چندبرگی.
- **رفع خطاها**: منابع خراب جایگزین شدند (Varzesh3 و Eghtesadnews حذف، CNN و Euronews و Hacker News اضافه)، منابع بدون خبر (Spiegel/WSJ/Google News) درست پیکربندی شدند، عناوین Google News از پسوند منبع پاک می‌شوند، تاریخ‌های نامعتبر و آینده اصلاح می‌شوند و خطای هر منبع جداگانه گزارش می‌شود.
- **تنوع منابع و پوشش چندمنبعی**: ۵۸ منبع رصد می‌شود که ۴۶ مورد آن رسانهٔ خارجی است؛ از جمله رسانه‌های فارسی‌زبان خارج از ایران: بی‌بی‌سی فارسی، ایران اینترنشنال، ایران‌وایر، کیهان لندن، یورونیوز فارسی، رادیو فردا، صدای آمریکا، دویچه‌وله فارسی و العربیه فارسی. برای هر خبر تعداد منابع منتشرکننده، نام آن منابع و درصد پوشش نسبت به پرپوشش‌ترین خبر نمایش داده می‌شود.

## اجرا

```bash
npm start          # سرور داشبورد روی پورت ۳۰۰۰ + به‌روزرسانی هر ۵ دقیقه
npm run update     # یک بار تولید داده (data.json و news.xlsx)
npm test           # تست زنجیرهٔ منابع نرخ (بدون نیاز به شبکه)
PORT=8080 npm start
```

مرورگر: `http://localhost:3000`

## فایل‌ها

| مسیر | توضیح |
| --- | --- |
| `index.html` | داشبورد تک‌صفحه‌ای؛ داده را از `data.json` می‌خواند و خودکار تازه می‌کند |
| `pipeline.mjs` | خط تولید: دریافت همهٔ خوراک‌ها، ترجمه، تحلیل، خروجی JSON و XLSX |
| `server.mjs` | سرور استاتیک + API وضعیت/به‌روزرسانی فوری + SSE + زمان‌بند ۵ دقیقه |
| `src/sources.mjs` | فهرست ۵۸ منبع (۴۶ رسانهٔ خارجی، از جمله ۹ رسانهٔ فارسی‌زبان خارج از ایران) با وزن اعتبار و خاستگاه |
| `src/analyze.mjs` | موضوع‌بندی، احساس، کلیدواژه، خوشه‌بندی و فرمول درصد اهمیت |
| `src/translate.mjs` | ترجمهٔ انگلیسی→فارسی با حافظهٔ نهان و چند تأمین‌کننده |
| `src/xlsx.mjs` | تولید فایل اکسل بدون وابستگی |
| `src/markets.mjs` | دریافت و یکسان‌سازی قیمت طلا، سکه و ارز (زنجیرهٔ TGJU → نرخ‌آرا → ایران‌مارکت + CoinGecko) |
| `test/markets.test.mjs` | تست زنجیرهٔ منابع نرخ: حالت عادی، دو منبع قطع، همهٔ منابع قطع، پوشش ناقص و آستانهٔ اختلاف |
| `.github/workflows/update.yml` | گردش‌کار گیت‌هاب: تست، تولید داده و انتشار روی Pages |
| `scheduler/` | راهنما و اسکریپت زمان‌بند ویندوزی برای تریگر دستی گردش‌کار |
| `data.json` | دادهٔ کامل داشبورد (همهٔ خبرها + تحلیل + بازار) |
| `news.xlsx` | خروجی اکسل: اخبار، موضوعات، بازار، منابع، تحلیل، خلاصه |

## میزبانی روی GitHub Pages

گردش‌کار `.github/workflows/update.yml` تست‌ها را اجرا می‌کند، `data.json` و `news.xlsx` را بازتولید می‌کند و خروجی را روی **GitHub Pages** منتشر می‌کند (نسخهٔ تولیدشده به‌صورت artifact منتشر می‌شود و `data.json`/`news.xlsx` موجود در مخزن، آخرین اجرای محلی است). تریگرها: `schedule` هر ۱۵ دقیقه، `push` روی مسیرهای کد، و `workflow_dispatch`؛ در پایان هر اجرا، اجرای بعدی حدود ۱۳ دقیقه بعد دوباره راه می‌اندازد تا فاصلهٔ به‌روزرسانی کوتاه‌تر شود.

برای اجرای آن:

1. در تنظیمات مخزن، Actions را فعال کنید و در **Settings → Pages** گزینهٔ Source را روی **GitHub Actions** بگذارید.
2. برای زنجیرهٔ اجرای خودکار، Secret با نام `NEWS_RADAR_TOKEN` بسازید (Personal access token با مجوز **Actions: Read and write** روی همین مخزن). بدون آن، اجراهای زمان‌بندی‌شده و دستی همچنان کار می‌کنند اما اجرای بعدی خودکار شروع نمی‌شود.
3. (اختیاری) برای سهمیهٔ بالاتر ترجمه، Secret با نام `MYMEMORY_EMAIL` بسازید.
4. (اختیاری) اگر ترجمهٔ اختصاصی دارید، `LIBRETRANSLATE_URL` و در صورت نیاز `LIBRETRANSLATE_KEY` را به‌عنوان Secret اضافه کنید.

> GitHub Actions حداقل بازهٔ ۵ دقیقه دارد و ممکن است چند دقیقه تأخیر داشته باشد؛ برای به‌روزرسانی هر ۵ دقیقه از `npm start` روی یک سرور استفاده کنید (بازهٔ سرور محلی با `UPDATE_INTERVAL_MINUTES` تغییر می‌کند).
