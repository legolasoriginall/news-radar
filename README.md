# رصد خبر — داشبورد زندهٔ تحلیل اخبار

داشبورد فارسی (RTL) برای رصد، ترجمه و تحلیل خودکار اخبار فارسی و بین‌المللی. داده‌ها از خوراک‌های RSS/Atom منابع مختلف خوانده می‌شوند، خبرهای انگلیسی به فارسی ترجمه می‌شوند و همهٔ شاخص‌ها به‌صورت درصد محاسبه و نمایش داده می‌شوند.

## چه چیزی اصلاح و اضافه شد

- **به‌روزرسانی خودکار هر ۵ دقیقه**: سرور داخلی (`server.mjs`) هر ۵ دقیقه داده را بازتولید می‌کند و صفحه از طریق نظرسنجی داده + رویدادهای SSE بدون بارگذاری مجدد تازه می‌شود؛ شمارندهٔ معکوس و دکمهٔ توقف/فعال‌سازی هم در داشبورد هست.
- **ترجمهٔ خودکار اخبار انگلیسی به فارسی**: عنوان و خلاصهٔ هر خبر انگلیسی با حافظهٔ نهان ترجمه می‌شود. موتور اصلی «Google دسته‌ای» است (چند متن در یک درخواست، حدود ۱۰ تا ۳۰ برابر سریع‌تر از تک‌درخواستی)؛ اگر Google از IP میزبان محدود شود، به‌طور خودکار Bing (چند نشست موازی) جایگزین می‌شود و MyMemory و LibreTranslate و در صورت تنظیم، LLM اختیاری هم در دسترس‌اند و متن اصلی نیز در داشبورد با دکمهٔ «نمایش متن اصلی» در دسترس است. درصد کیفیت ترجمه برای هر خبر و درصد پوشش ترجمه نمایش داده می‌شود؛ خبرهای در انتظار ترجمه با برچسب مشخص و متن اصلی نشان داده می‌شوند.
- **همهٔ خبرها**: هیچ محدودیت زمانی (۲۴ ساعته) روی خروجی نیست؛ همهٔ موارد خوراک هر منبع دریافت، یکسان‌سازی، حذف تکراری و خوشه‌بندی می‌شوند و با «نمایش بیشتر» و فیلترها قابل مرور است.
- **درصد در همه‌جا**: سهم هر موضوع، سهم هر منبع، درصد اهمیت هر خبر (با تفکیک تازگی/اعتبار منبع/پوشش/موضوع/احساس)، درصد پوشش خبرهای چندمنبعی، درصد احساس، درصد کیفیت ترجمه و درصد سلامت منابع.
- **قیمت طلا و دلار**: نرخ لحظه‌ای دلار، یورو، درهم، گرم طلای ۱۸ و ۲۴ عیار، مثقال، سکه امامی و انس طلای جهانی همراه با میزان تغییر و درصد تغییر روزانه در تابلوی «قیمت طلا، سکه و دلار» نمایش داده می‌شود؛ همهٔ نرخ‌های داخلی به **تومان** است. منبع اصلی TGJU است و اگر مسدود یا بی‌پاسخ باشد، به‌طور خودکار از منبع پشتیبان مستقل «نرخ‌آرا» (`nerkhara.com`) خوانده می‌شود و انس جهانی از CoinGecko تکمیل می‌شود. منشأ هر نرخ در `source` همان آیتم و در فهرست `markets.providers` ثبت می‌شود؛ **نمودار روند** دلار، گرم طلای ۱۸ عیار، سکه امامی و انس طلای جهانی در همان تابلو رسم می‌شود: نمونه‌ها در هر اجرا در `markets.history` ذخیره می‌شوند (تا ۷۲۰ نقطه) و بار اول از آرشیو روزانهٔ نرخ‌آرا و CoinGecko پر می‌شود تا نمودار از همان آغاز قابل خواندن باشد؛ اگر هیچ منبعی پاسخ ندهد، آخرین مقدار موفق با هشدار نمایش داده می‌شود. نرخ‌ها در `data.json` (کلید `markets`)، خلاصهٔ اجرایی و برگهٔ «بازار» فایل اکسل هم می‌آیند.
- **تحلیل کامل**: خلاصهٔ اجرایی، هفت شاخص تحلیلی، نمودار تراکم ساعتی ۲۴ ساعت گذشته، روند یک‌ساعتهٔ موضوع‌ها، هشدارهای خودکار و خروجی اکسل چندبرگی.
- **رفع خطاها**: منابع خراب جایگزین شدند (Varzesh3 و Eghtesadnews حذف، CNN و Euronews و Hacker News اضافه)، منابع بدون خبر (Spiegel/WSJ/Google News) درست پیکربندی شدند، عناوین Google News از پسوند منبع پاک می‌شوند، تاریخ‌های نامعتبر و آینده اصلاح می‌شوند و خطای هر منبع جداگانه گزارش می‌شود.
- **تنوع منابع و پوشش چندمنبعی**: ۵۸ منبع رصد می‌شود که ۴۶ مورد آن رسانهٔ خارجی است؛ از جمله رسانه‌های فارسی‌زبان خارج از ایران: بی‌بی‌سی فارسی، ایران اینترنشنال، ایران‌وایر، کیهان لندن، یورونیوز فارسی، رادیو فردا، صدای آمریکا، دویچه‌وله فارسی و العربیه فارسی. برای هر خبر تعداد منابع منتشرکننده، نام آن منابع و درصد پوشش نسبت به پرپوشش‌ترین خبر نمایش داده می‌شود.

## اجرا

```bash
npm start          # سرور داشبورد روی پورت ۳۰۰۰ + به‌روزرسانی هر ۵ دقیقه
npm run update     # یک بار تولید داده (data.json و news.xlsx)
PORT=8080 npm start
```

مرورگر: `http://localhost:3000`

## فایل‌ها

| مسیر | توضیح |
| --- | --- |
| `index.html` | داشبورد تک‌صفحه‌ای؛ داده را از `data.json` می‌خواند و خودکار تازه می‌کند |
| `pipeline.mjs` | خط تولید: دریافت همهٔ خوراک‌ها، ترجمه، تحلیل، خروجی JSON و XLSX |
| `server.mjs` | سرور استاتیک + API وضعیت/به‌روزرسانی فوری + SSE + زمان‌بند ۵ دقیقه |
| `src/sources.mjs` | فهرست ۵۸ منبع (۴۶ رسانهٔ خارجی، از جمله ۹ رسانهٔ فارسی‌زبان خارج از ایران) با وزن اعتبار و خاستگاه |
| `src/analyze.mjs` | موضوع‌بندی، احساس، کلیدواژه، خوشه‌بندی و فرمول درصد اهمیت |
| `src/translate.mjs` | ترجمهٔ انگلیسی→فارسی با حافظهٔ نهان و چند تأمین‌کننده |
| `src/xlsx.mjs` | تولید فایل اکسل بدون وابستگی |
| `src/markets.mjs` | دریافت و یکسان‌سازی قیمت طلا، سکه و ارز (TGJU با پشتیبان نرخ‌آرا و CoinGecko) |
| `data.json` | دادهٔ کامل داشبورد (همهٔ خبرها + تحلیل) |
| `news.xlsx` | خروجی اکسل: اخبار، موضوعات، بازار، منابع، تحلیل، خلاصه |

## میزبانی روی GitHub Pages

گردش‌کار `.github/workflows/update.yml` هر ۵ دقیقه اجرا می‌شود، `data.json` و `news.xlsx` را بازتولید و کامیت می‌کند. برای اجرای آن:

1. در تنظیمات مخزن، Actions را فعال و Pages را روی شاخهٔ `main` تنظیم کنید.
2. (اختیاری) برای سهمیهٔ بالاتر ترجمه، Secret با نام `MYMEMORY_EMAIL` بسازید.
3. اگر ترجمهٔ اختصاصی دارید، `LIBRETRANSLATE_URL` و در صورت نیاز `LIBRETRANSLATE_KEY` را به‌عنوان Secret اضافه کنید.

> GitHub Actions حداقل بازهٔ ۵ دقیقه دارد و ممکن است چند دقیقه تأخیر داشته باشد؛ برای به‌روزرسانی دقیق هر ۵ دقیقه از `npm start` روی یک سرور استفاده کنید.
